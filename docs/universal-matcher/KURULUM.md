# Mavi STABLE test kurulumu / 8601

1. Yalnız mavi CloudStream STABLE'daki eski EA-FB 8503 test eklentisini ve eski test deposunu kaldır.
2. Maviyi tamamen kapatıp yeniden aç.
3. Mavi → Eklentiler → Depo ekle:
   https://raw.githubusercontent.com/eaatabay/EA-FB/test/ea-fb-universal-matcher-v83-20261020/dist-universal-8601-test/repo.json
4. EA-FB UNIVERSAL 8601 TEST yükle. Mevcut eklenti ayarından deneyeceğin kaynakları aç ve oynatmayı dene.

Yeni paket kendi ayar alanıyla başlar; V83/8503 ayarlarını taşımaz veya değiştirmez. Mavide aynı anda yalnız tek EA-FB bulunmalı. Bilgisayar, ADB, Python, UID, profil veya izin/marker dosyası gerekmez. Normal CloudStream plugin yüklemesidir.

Kırmızı BETA V83'e işlem yok. Ted Lasso, doğru sezon/bölüm ve film/dizi ayrımını, kaynak seçimini ve gerçek oynatmayı kullanıcı Mi Box'ta test edecek. Yeni sürüm için cihaz başarı iddiası yoktur.

Tek adımlık geri alma: yalnız MAVİDE yeni test eklentisini kaldır.
