# Mavi STABLE / 8503 test kurulumu

1. Yalnız mavi CloudStream STABLE'da eski Bunny EA-FB eklentisini ve deposunu kaldır. Mavide yalnız yeni test EA-FB bulunacak.
2. Mavi CloudStream'i tamamen kapatıp yeniden aç.
3. Mavi STABLE → Ayarlar → Eklentiler → Depo ekle:
   https://raw.githubusercontent.com/eaatabay/EA-FB/test/ea-fb-series-name-codex-20261019/dist-series-codex-8503-test/repo.json
4. EA-FB SERIES CODEX 8503 TEST eklentisini yükle ve oynatmayı dene.

Bilgisayar, ADB, Python, profil değiştirme, izin veya marker dosyası gerekmez. 8503 normal CloudStream plugin load akışını kullanır. Önceki 8501/8502 doğrulama talimatları tarihsel sürümlere aittir; 8503'te uygulanmaz. Eski marker dosyası varsa 8503 onu okumaz veya şart koşmaz; elle temizleme adımı gerekmez.

Organize İşler (2026) S1E1/S1E8, eski Organize İşler (2005) ve Sazan Sarmalı (2019) ayrımı korunur. Dört kaynak: dizibox, diziyou, hdfilmcehennemi-nl, hdfilmcehennemi-land. Mi Box oynatması kullanıcı testine kadar doğrulanmamıştır.
